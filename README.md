# ♟️ Chess Club Manager & Discord Bot

A powerful, full-stack management suite for chess clubs. This project combines a high-performance **FastAPI** backend with a sleek, **React-based** moderator dashboard and an automated **Discord bot**, powered by **MongoDB** and **Groq AI**.

---

## 🚀 Key Features

### 🛠️ Admin Dashboard
- **Clean & Simple UI**: Modern interface with sidebar navigation and a polished aesthetic.
- **Tournament Control**: Create, search, filter, and manage tournaments with ease.
- **Leaderboard**: Real-time club performance tracking directly in the dashboard.
- **Automated Scheduling**: Support for one-time and recurring tournaments (daily/weekly/monthly).
- **Results Engine**: Publish winners directly to Discord with automatic role assignments.

### 🤖 Discord Bot
- **AI-Powered Announcements**: Dynamic messages generated by **Groq AI** (Llama 3).
- **Slash Commands**: `/puzzle`, `/leaderboard`, `/next`, `/link`, `/stats`, and more.
- **Automated Pings**: Notifies winners and reminds players of upcoming events.
- **Daily Puzzles**: High-quality board rendering with last-move highlights.

## 🌐 Deployment Guide

This project is designed to be deployed on **Render** (Backend) and **Vercel** (Frontend).

### 1. Database Setup (MongoDB Atlas)
1. Create a free cluster on [MongoDB Atlas](https://www.mongodb.com/cloud/atlas).
2. **Crucial:** Go to **Network Access** and click **Add IP Address**. Choose **Allow Access From Anywhere** (`0.0.0.0/0`). Render's IP addresses are dynamic and will be blocked otherwise.
3. Create a Database User and save the credentials.
4. Get your connection string (SRV format).

### 2. Backend Deployment (Render)
1. Fork/Push this repository to your GitHub.
2. Log in to [Render](https://render.com).
3. Click **New +** and select **Blueprint**.
4. Connect your GitHub repository.
5. Render will detect the `render.yaml` file and prompt you for environment variables.
6. Fill in the following (at minimum):
   - `MONGODB_URI`: Your Atlas connection string.
   - `DISCORD_BOT_TOKEN`: Your bot token from Discord Developer Portal.
   - `DISCORD_GUILD_ID`: Your server ID.
   - `GROQ_API_KEY`: Your key from [Groq Console](https://console.groq.com/).
   - `ADMIN_PASSWORD`: For dashboard login.
   - `ADMIN_TOKEN_SECRET`: A long random string.
7. Click **Apply**.

> **Note:** The backend runs both the API and the Discord Bot in the same process using FastAPI's lifespan events.

### 3. Frontend Deployment (Vercel)
1. Log in to [Vercel](https://vercel.com).
2. Click **Add New** -> **Project**.
3. Import your GitHub repository.
4. Set the **Root Directory** to `frontend`.
5. Under **Environment Variables**, add:
   - `VITE_API_BASE_URL`: The URL of your Render backend (e.g., `https://chess-club-backend.onrender.com`).
6. Click **Deploy**.

## 🛠️ Local Development

### Backend
```bash
cd backend
python -m venv venv
source venv/bin/activate # Windows: venv\Scripts\activate
pip install -r requirements.txt
# Create a .env file based on .env.example
uvicorn app.main:app --reload
```

### Frontend
```bash
cd frontend
npm install
# Create a .env file with VITE_API_BASE_URL=http://localhost:8000
npm run dev
```
