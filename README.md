# ♟️ Chess Club Manager & Discord Bot

A powerful, full-stack management suite for chess clubs. This project combines a high-performance **FastAPI** backend with a sleek, **React-based** moderator dashboard and an automated **Discord bot**, powered by **MongoDB** and **Groq AI**.

---

## 🚀 Key Features

### 🤖 Advanced Automation
- **Auto-Results**: The bot automatically polls Chess.com for finished tournaments. When a tournament ends, it fetches the winners, updates the leaderboard, and announces the results in Discord.
- **Auto-Role Assignment**: 
    - **Champion Role**: Automatically assigned to tournament winners (if their Discord account is linked).
    - **Verified Role**: Automatically assigned to users who link their Chess.com username via `/link`.
- **Winner Pings**: Automatically mentions winners in the results announcement to celebrate their victory.
- **Recurring Tournaments**: Plan tournaments once and let them repeat daily, weekly, or monthly. The system handles the scheduling for you.
- **Scheduled Reminders**: Pings the `@players` role 30 minutes before a tournament starts.

### 🛠️ Admin Dashboard
- **Clean & Simple UI**: Modern, minimal interface with sidebar navigation.
- **Tournament Control**: Create, edit, reschedule, or delete tournaments.
- **User Management**: Manually link/unlink Discord IDs with Chess.com usernames.
- **Live Leaderboard**: Real-time tracking of club performance based on tournament wins.
- **Automation Status**: View and manage the status of automated events.

### 🤖 Discord Bot
- **AI-Powered Announcements**: Dynamic messages generated by **Groq AI** (Llama 3) with a funny, chess-obsessed personality.
- **Interactive Commands**:
    - `/link <username>`: Connect your Chess.com account to get the Verified role.
    - `/puzzle`: Post a random high-quality Lichess puzzle.
    - `/leaderboard`: Show the top club players.
    - `/next`: Show details of the next upcoming tournament.
    - `/ask <question>`: Ask the AI Grandmaster anything (funny responses only).
    - `/stats [username]`: View Chess.com ratings and records for yourself or others.
- **Daily Puzzles**: Automated daily puzzle posts with beautiful board rendering and last-move highlights.

## 🌐 Deployment Guide

### 1. Database Setup (MongoDB Atlas)
1. Create a cluster on [MongoDB Atlas](https://www.mongodb.com/).
2. **Network Access:** Allow access from `0.0.0.0/0` (required for Render).
3. Save your connection string (e.g., `mongodb+srv://...`).

### 2. Backend Deployment (Render)
1. Fork this repository.
2. Create a **Blueprint** on Render and connect your fork.
3. Configure the environment variables (see `backend/.env.example`):
   - `DISCORD_BOT_TOKEN`: From [Discord Developer Portal](https://discord.com/developers/applications).
   - `GROQ_API_KEY`: From [Groq Console](https://console.groq.com/).
   - `DISCORD_GUILD_ID`, `DISCORD_ANNOUNCEMENT_CHANNEL_ID`, etc.
   - `ADMIN_PASSWORD`: Your secret dashboard password.

### 3. Frontend Deployment (Vercel)
1. Create a new project on Vercel.
2. Set the **Root Directory** to `frontend`.
3. Set the environment variable:
   - `VITE_API_BASE_URL`: Your Render backend URL.

## 🛠️ Local Development

### Backend
```bash
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
# Copy .env.example to .env and fill in keys
uvicorn app.main:app --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
